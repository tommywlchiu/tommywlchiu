# Tommy Chiu

Software engineer building AI-powered products, with a focus on pairing LLM judgment with deterministic code for reliability.

## Projects

**[ForkOver](https://github.com/tommywlchiu/ForkOver)**
A bill-splitting app for friend groups. Scan a receipt, AI extracts the line items, and each person claims what they ordered.

**[newsletter-demo](https://github.com/tommywlchiu/newsletter-demo)**
An agent-orchestrated newsletter pipeline: Perplexity research → fact-check gate → branded infographics → MJML email → Gmail draft. LLMs handle research and editorial judgment, while deterministic scripts handle everything that must be correct every time. The README documents what failed along the way, not just what worked.
